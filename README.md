# creative SJTUrednote

面向高校、文旅等机构官号的小红书 / 抖音创意调研技能。由真实的校园内容研究流程提炼，适用于 Codex 等支持 `SKILL.md` 的助手。

它会先学习目标账号的原创风格，再寻找近期参考内容，核验点赞与评论，给出可制作的改编方向和推荐理由。支持只整理已有候选清单。

## 安装

下载或克隆本仓库，将 `creative-sjtu-rednote` 文件夹复制到你的 Codex 技能目录（`$CODEX_HOME/skills`，未设置时通常为 `~/.codex/skills`）。不要把仓库外层文件夹当作技能文件夹。重新载入会话后使用 `$creative-sjtu-rednote` 调用。

技能入口：[SKILL.md](creative-sjtu-rednote/SKILL.md)。需要实际可用的浏览器控制或平台连接器；本仓库不包含爬虫、登录凭据或平台数据接口，不保证访问任何平台。

## 使用示例

```text
使用 $creative-sjtu-rednote，先多看一些上海交通大学官号的原创视频和图文，
排除新闻、获奖快讯和领导讲话。参考其他985高校与文旅官号，
找10条可改编的创意，优先近15天，高互动作品可以放宽到30天或更久。
综合点赞和评论判断，允许偏文艺风，忽略恶意留言。
每条给原帖链接和推荐理由；没有明确特殊节点或近期热梗就省略对应条目。
```

```text
使用 $creative-sjtu-rednote，按我提供的候选表整理推荐理由。
保留核验日期与真实互动数，不推测观看量、衍生视频数量，给出适合本校的改编方向。
```

## 输出与边界

- 账号风格分析、候选对照表、推荐理由及具体改编方向。
- 数据缺失就说明缺失；编辑时间不等于首发时间；评论总量不等于正面反馈。
- 不把定向样本当作全站榜单，不把单条爆款直接称为近期热梗。
- 特殊节点与近期热梗都是有证据才出现的可选条目。
- 高互动与近期创意分开说明，不承诺改编后获得同等传播效果。
- 公开包不含原始调研记录、平台访问令牌、个人账号资料或原帖媒体。
