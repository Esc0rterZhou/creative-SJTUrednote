# 输出模板与证据口径

## 完整调研

开头写：核验时点、样本来源、时间窗口，以及是否包含旧案例或热度有限的创意样本。

先用具体作品归纳目标账号风格，再用表格列出：序号、标题/原帖链接、作者及账号属性、日期及其口径、视频/图文、点赞、评论、推荐类别、可改编方向。未知数据写“未核验”，不填0。

每条改编方向写拟定标题、开头设计、核心画面/图文结构、预计时长/页数和关键制作条件。篇幅依用户需求调整，不把简单推荐理由扩成完整拍摄方案。

## 精简推荐理由

下面是**完全虚构的格式演示**，不是已发布作品、真实互动数据或热度结论：

**某高校《把春天折进课本》**

小红书链接：实际交付时填写已核验原帖链接。

推荐理由：

1. **创意形式鲜明：**用翻书动作衔接校园花景，可改编为学生在不同校园地点接力翻页，兼顾人物与地标。
2. **点赞1.2万，评论320条**，为本虚构示例中的演示数值。
3. **特殊节点：**仅当实际原帖明确结合春分等节点时添加此条；实际输出不保留本条件说明。

若没有明确节点或热梗，实际推荐理由只有前两项即可。不要补“没有特殊节点”“尚未形成热梗”。多条观看量、衍生数量都不可得时，在开头统一说明一次。

## 可选数据记录

需要机器可读记录时，每条保存：标题、作者、身份核验依据、原帖URL、核验时点、日期显示原文、日期类型（发布/编辑/相对）、内容形式、点赞原始显示、评论原始显示、可得的观看量、数据页来源、节点/热梗证据、改编建议与局限。

未知值用null或缺省字段；不要将约数写成精确值。公开数据另做脱敏副本，不直接提交带临时令牌的研究原始记录。
