# 校园与文旅新媒体选题研究

先理解目标账号，再寻找值得借鉴的创意形式。区分原帖事实、热度证据与改编建议；按用户要求的数量、时间和输出格式交付。

## 确定研究口径

- 沿用会话中的目标账号、参考案例、排除项和审美偏好。缺少目标账号等关键条件时再询问；已有明确输入则继续工作。
- 未指定时，以当前用户时区日期为基准，优先近15天，扩展至30天；更旧内容须因突出互动或独特形式单独说明。默认给10条，不足时说明实际数量，不用低质量案例补齐。
- 校园创意研究默认排除领导讲话、获奖快讯、新闻通稿、通知和单纯成果发布。其他高校也用同一口径；用户另有范围时服从用户。
- 默认重点看高校官号（可优先985）、政府文旅官号；个人及商业账号可补充创意，但必须明确属性，不能冒充官方样本。

## 先学习目标账号

验证主页身份与作品归属，不凭同名认定官号。多读近期原创视频和图文，再用较早代表作补足形式样本；不要从一条爆款归纳整个账号。

记录具体形式：开头如何吸引、人物或地标如何入镜、镜头与转场、文字与画面关系、时长或图文页数、互动设计、情绪与语言。视频未完整播放、音频未核实或图片加载不全时，限定结论范围。

提炼可执行的风格特征，例如学生参与、校园地标、实物与画面互动、克制的文艺表达。检查目标账号是否已做过相同创意，优先提出有差异的新版本。

## 搜索、核验与筛选

使用可用的浏览器或平台连接器访问真实页面。用户已登录时优先沿用该会话；不要求重新提供密码，不绕过登录、访问控制或验证码。工具断连时说明具体阻碍，独立完成不依赖访问的工作，不把搜索摘要或旧数据当作实时核验。

1. 从目标官号及对标官号查找候选，再按形式搜索，如校园转场、互动视频、校园季节、原创画作、食堂创意、地图叙事。平台时间筛选不足15/30天时逐条核对日期，不声称平台提供了不存在的筛选项。
2. 打开候选详情核验标题、作者、日期、作品形式及点赞/评论。只看搜索卡片的记录标为初筛，不能伪装成详情核验。
3. 综合点赞、评论、时效、独特性、账号适配与制作成本判断，不用单一点赞数冒充综合排名。区分“高互动案例”和“热度有限的近期创意样本”。
4. 做适量横向比较并去重。不要把同一模板的多个近似作品凑成多条选题；每条说明可借鉴的机制与适合目标账号的具体改法。
5. 优先读取正文和互动栏。用户要求忽略恶意留言时不展开分析或复述；若分析有效评论，只总结与内容有关的需求或反馈。

## 数据与证据规则

- 记录核验日期、页面来源及显示原值；“万”“10万+”保留粒度，空白不当作0。观看量不能由点赞推算，互动率没有曝光分母就不计算。
- 详情页与搜索页冲突时并列注明来源，不擅自合并。平台评论总数不等于正向反馈人数，也不等于作品形式带来的关注度。
- “编辑于”是编辑日期；“2天前”等相对日期保留原文，换算时用“约”，不冒充精确首发时间。
- 衍生视频数量必须来自明确口径：如话题页显示的作品数，或本次实际核验的独立模仿作品数。前者不自动等于该原帖的衍生量，后者仅是已发现样本下限。未知则省略或统一注明未核验。
- “近期热梗”需要有时间依据的跨作品使用证据，并说明具体梗与来源；单个高赞、流行音乐、标签、AI画风或容易模仿均不足以证明。
- “特殊节点”只在日期、标题、正文等有明确节日、节气或事件关联时写。可能适合迎新、校庆只是改编建议，不是原帖节点事实。
- 不同作者规模和发布时间不同，绝对互动数不能证明算法偏好。定向样本不写成全站榜单或平台用户总体偏好；用户要求偏好统计时，另行定义样本、类别与局限。
- 署名转载、AI生成、商业账号和真实性未独立核实的人物故事，按实际证据说明。不得把所有热度归因于剪辑或创意形式。

## 交付

完整调研给出简短账号风格结论、候选对照表、逐条推荐理由与改编方向，注明核验日期及关键局限。每条至少有原帖链接、作者、日期口径、形式、点赞、评论、入选理由。仅要求重写推荐理由时，使用现有记录并注明数据时点，不强行重新做调研。

推荐理由遵循以下顺序，只保留有证据的项目：

1. 高数据或创意价值：具体吸引机制、目标账号适配，以及有证据时的衍生规模。热度低的案例坦率写“近期创意参考”，不硬写高关注度。
2. 已核验互动数据：观看量、点赞、评论中实际可获得的字段。共性缺失可在开头统一说明。
3. 特殊节点：仅有证据时出现。
4. 近期热梗：仅有证据时出现。

缺少节点或热梗时省略整个条目，不逐条填“不是节点”“不是热梗”。适配建议不冒充爆款保证。详尽格式及虚构示例见 [references/output-guide.md](references/output-guide.md)，需要输出模板时再读。

## 链接与公开内容

交给用户的研究资料可保留确保可访问所需的平台链接，但不公开发布会话凭据、Cookie、账号私密信息或临时访问令牌。开源示例使用无令牌链接、明确标为虚构的示例或平台首页；清理参数后不能保证原帖可打开。公开发布原帖文字或媒体需另有授权，不将调研等同于转载授权。
